# Strain catalog

Default labels use real strain names. Growth, quality, price, and effect
parameters remain custom Minecraft game balance.

| In-game name | Command alias | Historical persistence ID |
|---|---|---|
| Blueberry | `blueberry` | `berry_fog` |
| Hindu Kush | `hindu_kush` | `concrete_kush` |
| Super Lemon Haze | `super_lemon_haze` | `lemon_static` |
| Skunk #1 | `skunk_1` | `green_alley` |
| Super Silver Haze | `super_silver_haze` | `neon_haze` |
| White Widow | `white_widow` | `night_widow` |
| Purple #1 | `purple_1` | `purple_crash` |
| Northern Lights | `northern_lights` | `velvet_smoke` |

| Jack Herer | `jack_herer` | `royal_static` |
| Black Domina | `black_domina` | `black_orchard` |
| OG Kush | `og_kush` | `verdant_vice` |

Example: `/vv admin seed PlayerName super_lemon_haze`.
TAB suggestions use catalog names. Existing identifiers remain valid;
saved batches, signatures, genetics, and the market retain continuity.
Do not change existing strain keys in `strains.yml`.

On upgrade, the plugin replaces only unchanged legacy default labels.
It backs up the configuration before saving. Administrator-defined names
and gameplay parameters are preserved. New player-created lines may still
receive names through the genetics system.

The pack depicts items and strains as stylized pixel-art illustrations.
Colors help distinguish inventory variants; they are not photographs or
documentation of real strain characteristics.
